# Usta

Строительное приложение для Кыргызстана: мастера, материалы, аренда техники и заказы, а главный экран построен по этапам стройки. Это первая тестовая версия: только интерфейс и тестовые данные, без сервера.

## Как скачать на телефон (Android)

1. Откройте раздел **Releases** этого репозитория (справа на главной странице репозитория).
2. В последней сборке нажмите **Usta.apk**.
3. Откройте скачанный файл. Если Android спросит, разрешите установку из этого источника.

Прямая ссылка на последнюю сборку:
`https://github.com/<владелец>/<репозиторий>/releases/latest/download/Usta.apk`

Если репозиторий приватный, скачать файл сможет только тот, кто вошёл в GitHub и имеет доступ к репозиторию.

## Как обновляется сборка

При каждой отправке кода в репозиторий GitHub сам собирает новый APK (вкладка **Actions**) и публикует его в **Releases**. Сборка занимает около 10 минут.

## iPhone

Установить приложение на iPhone по прямой ссылке нельзя. Нужен аккаунт разработчика Apple (99 $ в год) и TestFlight.

## Что внутри

- `lib/` — код приложения на Flutter
- `assets/` — шрифты Onest и Unbounded (лицензия OFL) и иконка
- `docs/` — описание продукта, дизайна, правил ИИ и границ первой версии
- `CLAUDE.md`, `START.md` — инструкции и промпты для Claude Code
