# Строительное приложение для Кыргызстана

## Как со мной работать
- Я не программист. Объясняй простым языком, по-русски. Термин, без которого нельзя, объясняй одной фразой.
- Работай этапами. После каждого этапа остановись: что сделано, как запустить и проверить, что дальше. Жди моего «ок». Сам к следующему этапу не переходи.
- Не хватает информации для решения — задай вопрос, не угадывай.
- Видишь проблему в моей идее (технически, юридически, по деньгам) — скажи прямо и сразу, предложи альтернативу.
- Каждый этап должен запускаться. Не оставляй недописанный код.
- Всё, что стоит денег или требует регистрации аккаунта (сервер, SMS, ИИ-API), сначала согласуй со мной.

## Что за проект
Одно приложение для всей строительной отрасли Кыргызстана: мастера, материалы, аренда техники, заказы. Только стройка, никакой посторонней рекламы. Главная фишка: ИИ-помощник и навигация по этапам строительства. Старт: Бишкек.

## Уже решено
- Android и iOS, одна кодовая база. Стек подтверждаем на этапе 1.
- Языки интерфейса: кыргызский и русский.
- Вход по номеру телефона и SMS-коду, без паролей.
- Должно работать на недорогих Android-телефонах и при слабом интернете.
- Создание заказа максимум за 3 шага.
- Один тип аккаунта для всех, роль при регистрации не выбирается.

## Текущее состояние кода
- Стек: Flutter, одна кодовая база. Сейчас собирается только Android.
- Сборка APK идёт автоматически на GitHub (`.github/workflows/android.yml`) при каждой отправке кода. Готовый файл публикуется в Releases. Папка `android/` не хранится в репозитории: её создаёт `flutter create` во время сборки.
- Сделан главный экран по макету с тестовыми данными, без сервера: `lib/screens.dart` (экраны), `lib/widgets.dart` (карточки, линия этапов, ИИ-блок), `lib/data.dart` (тестовые данные и состояние), `lib/theme.dart` (цвета, шрифты, сетка), `lib/icons.dart` (линейные иконки).
- ИИ, чат, вход по SMS и создание заказа пока заглушки с пояснением «появится на следующем этапе».
- Шрифты переменные (Onest и Unbounded), толщина задаётся через `fontVariations`. В Unbounded нет букв ң, ө, ү: при добавлении кыргызского интерфейса заголовки должны откатываться на Onest.

## Не делать в MVP
