# Первая версия (MVP)

Цель: проверить, что заказчик и мастер в Бишкеке находят друг друга через приложение. Только основной путь.

## Входит
1. Вход по номеру телефона и SMS-коду
2. Профиль, включая необязательный профиль исполнителя
3. Создание заказа за 3 шага: что нужно → описание (голос, фото или текст) → отправить
4. Отклики на заказы
5. Чат внутри приложения и кнопка связи через WhatsApp/Telegram
6. ИИ-оценка по фото: тип работы, ориентировочная цена, список материалов (без сметы)
7. Главный экран с этапами строительства
8. Простая админка для меня: добавлять мастеров и продавцов вручную

## Не входит
Сметы, учёт материалов, аналитика, видеозвонки, оплата этапами, индекс цен, знак «Проверенный» с документами, ИИ-консультант для исполнителей.

## Критерий «готово» для каждого этапа
- Запускается на телефоне или эмуляторе по инструкции.
- Работает на русском и кыргызском.
- Не ломается без интернета (показывает понятное сообщение).
